## 今天搞清的五点

1. **集合变量导出的是 `initial`，不是 `current`**：current 只在本机生效，导出必须填 initial
2. **环境变量优先于集合变量**：在 `Github API` 环境下跑，`{{baseUrl}}` 被解析成 `api.github.com`，`/status/500` 变成 404
3. **断言要问“删掉它，哪类问题就没人发现了”**：状态码断言有替代，安全类断言没有
4. **鉴权用例只能证明“凭证带上了”**：httpbin 只验格式不验值，证明不了业务鉴权
5. **“别人能跑”要用“新工作区 + 无环境”验证**：在自己的环境里跑绿不算数
