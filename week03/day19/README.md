## 今天搞清的四个点

1. **Runner = 一次执行 + 出报告**：10 条请求几十秒跑完，输出通过率和失败详情
2. **数据驱动靠 `csv.DictReader + int()`**：CSV 有几行就跑几轮，断言里读当前行
3. **三种"假通过"**：断言太弱 / **数据文件为空** / 请求被跳过
4. **Mock 的本质是"控制返回"**：Postman Mock 或 httpbin 的 `/status/500`、`/delay/3` 都算
