## 二、新知识：窗口函数三件套

今天唯一的新工具。语法骨架：

```sql
函数() OVER (
    PARTITION BY 分组键      -- 可选：按什么分组（相当于 GROUP BY）
    ORDER BY 排序键          -- 组内按什么排
    [ROWS BETWEEN ... ]      -- 可选：窗口范围（默认到当前行）
)
```

| 函数 | 结果 | 用在哪题 |
|---|---|---|
| `ROW_NUMBER()` | 1, 2, 3, 4（**不重复**） | 取"每组第一条" |
| `RANK()` | 1, 2, 2, **4**（跳号） | — |
| `DENSE_RANK()` | 1, 2, 2, **3**（不跳号） | **185** |
| `SUM(x) OVER (ORDER BY y)` | 累计求和 | **1204** |
| `LAG(x)` / `LEAD(x)` | 上一行 / 下一行 | 前后行比较 |

**与 `GROUP BY` 的根本区别**：

| | `GROUP BY` + 聚合 | 窗口函数 |
|---|---|---|
| 行数 | **会减少**（每组只剩 1 行） | **不变**（每行都保留，多一列排名/累计） |
| 用在哪 | `SELECT` / `HAVING` | **只能写在 `SELECT` 里** |
| 能不能筛选 | `HAVING` 直接筛 | **不能直接筛** → 要包一层子查询再 `WHERE` |

```sql
-- 典型结构：先算排名，再筛
SELECT * FROM (
    SELECT department, name, salary,
           DENSE_RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS rk
    FROM Employee
) t
WHERE rk <= 3;
```

## 三、"全部/所有"（∀）的两种翻译

对应 `SQL 解题方法.md` §2 的核心结论：**SQL 没有 `FORALL`**。

| 形态 | 翻译方式 | 用在 |
|---|---|---|
| **数量比对** | "买下了所有产品" = `COUNT(DISTINCT 买过的) = 产品总数` | 1045 |
| **极值满足** | "所有销售都在区间内" = `MIN >= 开始 AND MAX <= 结束` | 585、1084 |
| **反选** | "没有例外" = `NOT EXISTS (反例)` | 1084 另一种解法 |

**记一句**：**`∀` = `¬∃¬`（不存在反例）= 极值满足 = 数量比对**。

## 五、`NOT IN` 的 NULL 陷阱（验证题）

1978 这题是验证 Day 12 结论的机会：

```sql
-- ❌ 子查询一旦返回 NULL，整条结果变空集
WHERE manager_id NOT IN (SELECT id FROM Employees WHERE 已离职)

-- ✅ 安全写法
WHERE NOT EXISTS (SELECT 1 FROM Employees e WHERE e.id = t.manager_id)
```

**判据**：`NOT IN` 的子查询里只要可能有 NULL，就换 `NOT EXISTS`。

## 六、还没搞懂的

1. **NOT IN 和 NOT EXISTS 遇 NULL 结果相反** —— 知道"一个排除、一个保留"，
   但**说不出为什么**（NOT IN 是 x<>NULL 变 UNKNOWN；NOT EXISTS 是"找不到"= TRUE）
2. **"一行 NULL" vs "零行"** —— 知道 `SELECT (子查询)` 能返 NULL，
   但**说不清"值的位置"和"表的位置"的区别**
3. **COUNT 到底数什么** —— 我原以为"COUNT(*) 遇 NULL 给 0"，
   实际是"**空集**给 0；有行但值全 NULL 时给行数"
4. **ROW_NUMBER 到底跳不跳号** —— 我说它跳号（错，跳号的是 RANK），
   而差值分组法恰恰依赖它**不跳号**
