# 题库索引（唯一复习入口）

> **复习只看这个文件。**
> 完整答案在笔记里，「展开」列只放**指针** —— **绝不在这里抄答案**。

## 用法

- 每次复习只扫「状态」列，**跳过 ✅**
- 🔁 / ⬜ 的题，按「展开」去翻笔记 → **合上笔记，用一句话讲出来**
- 讲得出来 → 改 ✅；卡住 → 留 🔁
- 连续三次 ✅ → 移到文末「归档区」，不再复习

## 状态说明

| 标记 | 含义 |
|---|---|
| ⬜ | 未掌握 |
| 🔁 | 要复习（讲得出来但会卡） |
| ✅ | 已掌握（不看笔记能讲清） |
| 📦 | 已归档（连续三次 ✅） |
