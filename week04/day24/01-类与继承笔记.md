## 一、类与对象

### 1.1 函数版 vs 类版：cfg 从“参数”变成“属性”

| 方面 | 函数版 | 类版 |
| --- | --- | --- |
| cfg 在哪 | 每次调用时传 | 存在对象里（self.cfg） |
| 调用方式 | run_case(cfg, row) | runner.run_case(row) |
| 传错参数的风险 | 高（顺序、个数） | 低（出生时定一次） |

### 1.2 self 到底是谁（贴验证输出）

| 部分 | 作用 |
| --- | --- |
| __init__ | 构造方法，User("张三", 18) 时自动调用 |
| self | 指代“这个对象自己”，Python 必须显式写（Java 的 this 可省，Python 不行） |
| self.name = name | 把传入的参数存到对象身上 |

**验证输入：**

```py
class A:
    def who(self):
        print("self 是:", self)

a = A()
a.who()
```

**验证输出：**

```text
self 是: <__main__.A object at 0x00000169B2ED6360>
```

### 1.3 实例属性 vs 类属性（贴污染实验）

**污染实验输入：**

```py
class Bad:    # 定义一个叫Bad的类
    items = []    # 类属性，值是【可变对象】（空列表）—— 这是本示例的病根
    def add(self, x):    # 定义一个叫add的方法
         # self.items 找不到实例属性 → 用类属性 Bad.items
        self.items.append(x)   # 原地追加，改的是那个共享列表

b1, b2 = Bad(), Bad()   # 创建两个Bad类的实例
b1.add(1)   # b1 自己没有 items → 找到【类属性】并原地 append
            # 所以改的是类属性，b2 看到同一份
print(b2.items)              # [1] ← b2 也被污染了
```

**污染实验输出：**

```text
[1]
```

- 证明 b1 添加的 items 最终加在类属性中，污染了 b2 的结果

### 1.4 方法 vs 函数的区别

| 方面 | 函数 | 方法 |
| --- | --- | --- |
| 定义 | def f(x): | def m(self, x): |
| 第一个参数 | 无要求 | self |
| 调用 | f(1) | obj.m(1) |

## 二、封装

### 2.1 `_` 和 `__` 的区别（贴实验）

**输入：**

```py
class A:
    def __init__(self):
        self.pub = 1
        self._prot = 2
        self.__priv = 3


a = A()
print(a.pub, a._prot) 
print(a.__priv)
print(a._A__priv) 
```

**`_`输出：**

```text
1 2
```

**`__`输出：**

```text
AttributeError: 'A' object has no attribute '__priv'. Did you mean: '_A__priv'?
```

- `_` 允许外部访问，`__` 不允许外部访问。
- 若想外部访问 `__` ，需要改成 _类名__name。

### 2.2 @property 用在哪、不用在哪

| 场景 | 用吗 |
| --- | --- |
| 取值/赋值要校验 | ✅ |
| 要算出来（比如 full_name = first + last） | ✅ |
| 只是存个值 | ❌ 直接 self.x |

## 三、继承

### 3.1 最小继承例子（Animal / Dog）

```py
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

    def intro(self):
        return "我是%s，%s" % (self.name, self.speak())


class Dog(Animal):                 # 继承 Animal
    def speak(self):               # 重写
        return "汪汪"


class Cat(Animal):
    def speak(self):
        return "喵喵"


d = Dog("旺财")
e = Cat("咪咪")
print(d.intro())        # 我是旺财，汪汪
print(e.intro())   # 我是咪咪，喵喵
```

### 3.2 super() 为什么比直接写父类名好

- super() 在多重继承时更安全，且父类改名不用改这里。

### 3.3 is-a vs has-a：我举的两个例子

| 关系 | 用什么 | 例 |
| --- | --- | --- |
| is-a（是一种） | 继承 | Dog 是一种 Animal |
| has-a（有一个） | 组合（属性） | ReportRunner 有一个 requests 会话 |

### 3.4 继承层数超过 2 的风险

| 层数 | 建议 |
| --- | --- |
| 1 层（基类 + 子类） | ✅ 常见且清晰 |
| 2 层 | ⚠️ 想清楚再用 |
| 3 层以上 | ❌ 基本是设计问题，考虑组合 |
