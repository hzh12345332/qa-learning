## 今天搞清的四个点

1. **断言分四层**：协议 / 结构 / 值 / 时间。**只断言状态码等于没测**
2. **接口串联靠集合变量**：上一步的结果存进 `pm.collectionVariables`，下一条用 `{{变量}}`
3. **串联用例必须按顺序跑** —— 单独跑会用到上次的旧值，**造成假通过**
4. **数据驱动 = 一份用例跑 N 组数据**；CSV 读出来是字符串，断言状态码要 `Number()`

## 备注

- `users.csv` 里的 `abc,400` 是**故意**的：测 userId 类型错时应该 400，不是 500
- 动态变量 `{{$guid}}` 每次发送都变，**不能用来断言具体值**，只能验格式
- 时间断言今天**故意没加** —— 公网接口（httpbin）会随机失败
- JSON Schema 的 `required` 只管"不能少"，**不管"不能多"**
