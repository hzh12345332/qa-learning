### 2. 哪个坑最值得写进文档？

**选：`mysql < file.sql` 报 1064 + 中文乱码。**

| 为什么是它 |
| --- |
| **症状最有欺骗性** —— 报的是"语法错误"，会让你去改 SQL，实际是编码问题 |
| **根因链条长** —— 文件 UTF-8 → 客户端 charset 是 GBK → 多字节吃掉了换行 → 语法错 |
| **可迁移** —— 以后接口传中文、CSV 导入、日志乱码，都是同一个根因 |

其余 6 条已写进 `01-云服务器环境搭建文档.md` §四，此处不重复。
