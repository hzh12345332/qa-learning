备注：

- **JWT 的 payload 是 base64 明文，不是加密** —— 安全性靠签名防篡改，不靠“看不见”
- **JWT 无法立即撤销**，工程解法是「短有效期 `access_token` + 可撤销的 `refresh_token`」
- **Cookie 方案怕 CSRF，Token 方案怕 XSS** —— 一个是被浏览器自动带，一个是被 JS 偷
- 「注销后凭证立即失效」是三种方案的分水岭。测到 JWT 不生效时，**先确认设计意图**，再决定报不报
- 实验产物 `cookies.txt` 属于临时文件，不入库
