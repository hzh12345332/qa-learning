# Day 6 全流程走查

- **日期**：2026-10-24

## 理论

| 检查维度 | 要问自己的问题 |
| --- | --- |
| 正常流 | 主流程每一步的预期结果是否唯一？ |
| 异常流 | 网络中断、请求超时、支付失败、重复提交、服务报错，覆盖了吗？ |
| 边界值 | 数量 0/1/最大、金额 0.01/大额、字符串长度上下限，测了吗？ |
| 权限 | 未登录、登录过期、越权访问他人数据，会怎样？ |
| 数据一致性 | 库存、金额、订单状态，前后是否同步？ |
| 并发 | 同一账号两端同时操作、超卖，会怎样？ |
| 兼容性 | 浏览器、分辨率、移动端，都考虑了吗？ |
| 安全 | SQL 注入、XSS、越权、敏感信息明文？ |
| 易用性 | 提示语、加载态、错误恢复、空状态，友好吗？ |

> 练习要求：用 saucedemo 完整走一遍 —— 登录 → 商品列表 → 排序 → 商品详情 → 加入购物车 → 购物车增删 → 结算信息 → 订单概览 → 完成订单 → 退出登录。边走边记录页面元素和状态变化
