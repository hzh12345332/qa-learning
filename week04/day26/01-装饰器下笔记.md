## 二、@retry

### 2.1 我的 retry 参数表（times/delay/exceptions 各什么意思）

| 参数 | 含义 | 单位 | 示例 | 默认 |
| --- | --- | --- | --- | --- |
| times | 总共尝试几次（不是“重试几次”） | 次 | 3 | 3 |
| delay | 每次失败后等多久再试 | 秒 | 0.5 | 0 |
| exceptions | 只对这些异常重试 | 元组 | (ValueError,) | (Exception,) |

- @retry(times, delay, exceptions) = 最多试 times 次； 只在抛了 exceptions 里的异常时才再试； 每两次之间等 delay 秒； 全失败就把最后一个异常原样抛出； 成功一次就立刻返回。

### 2.2 "总共 3 次" vs "重试 3 次"，我选了哪个、为什么

- 我选的 "总共3次"
- range(times)就是 "总共3次" 。"重试 3 次" 应该是range(times+1)= 首次 1 次 + 重试 3 次 = 总共 4 次

### 2.4 哪些接口不能加 retry（举两个）

- 非幂等(重复操作返回不同结果)的接口不能加retry
- 例如：POST /orders（下单）；POST /pay（扣款）

### 2.5 为什么 AssertionError 不该被重试

- 断言失败会重复执行 3 次
- 测试变慢 3 倍
- 断言失败是逻辑错误，不是偶发，重试会掩盖问题

## 三、@log_calls

### 3.1 第一版（明文密码）的输出截图 → 说明问题

**输入：**

```py
from functools import wraps

def log_calls(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("[call] %s(%s, %s)" % (func.__name__, args, kwargs))
        return func(*args, **kwargs)
    return wrapper
@log_calls
def login(username, password):
    print("登录成功：", username)
login("zhangsan", password ="P@ssw0rd!")

print(login)     # 验证 @wraps 生效：应该显示 <function login ...> 而不是 <function wrapper ...>
```
