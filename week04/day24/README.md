## 今天搞清的五点

1. 类属性是所有实例共用的，实例属性是实例内部使用的，如果类属性使用了可变对象（如：list/dict/set）可能会导致被污染
2. `_` 允许外部访问，`__` 不允许外部访问。
3. 子类继承父类；super() 的好处是父类改名时不用同步改子类。
4. 函数版 vs 类版，最大的区别是：“数据”从“参数”变成了“属性”
5. if `__name__ == "__main__"` 让同一个 .py 文件既可以运行也可以被 import

## 备注（今天的坑）

- `_init_` 少写一个下划线 → 不报错但 `__init__` 没被调用
- `def main()` 缩进进类里 → `NameError: runner is not defined`
- 没保存就运行 → 跑的是旧代码
