# 2026-11-18 ｜ 给 `08-模拟 500` 补三层断言

题面见 `练习/README.md` 的「11/18」一节。对象是 Postman 集合里的 `08-模拟 500`。

## 四段脚本（Postman → `08-模拟 500` → Scripts → After response）

```js
pm.test("服务端错误返回 500", function () {
    pm.response.to.have.status(500);
});

pm.test("错误响应没有 body", function () {
    pm.expect(pm.response.text()).to.be.empty;
});

pm.test("5xx 不泄露堆栈或内网路径", function () {
    const t = pm.response.text().toLowerCase();
    const hits = ["traceback", "sql", "/home/", "password"].filter(function (kw) {
        return t.includes(kw);
    });
    pm.expect(hits, "泄露了：" + hits.join("、")).to.be.empty;
});

// 自测：证明 L3 真能识别全部 4 个词（只留在练习里，不进交付集合）
pm.test("自测：L3 能识别全部 4 个关键词", function () {
    const fake = [
        "Traceback (most recent call last):",
        "  File \"/home/app/main.py\", line 42",
        "sql = \"SELECT * FROM users WHERE password = 'x'\""
    ].join("\n");
    const hits = ["traceback", "sql", "/home/", "password"].filter(function (kw) {
        return fake.toLowerCase().includes(kw);
    });
    pm.expect(hits.length, "只抓到：" + hits.join("、")).to.equal(4);
});
```

## 结果

```
4/4 PASSED
- 服务端错误返回 500
- 错误响应没有 body
- 5xx 不泄露堆栈或内网路径
- 自测：L3 能识别全部 4 个关键词
```

## 卡点（三个，全是"静默错误"）

| 坑 | 表现 | 正确做法 |
|---|---|---|
| `.include()` 只吃**一个**参数 | `.include("traceback", "sql", ...)` 不报错，但只查第一个 | `forEach` / `filter` 逐个查 |
| 一条 `pm.test` 里循环，**命中即中断** | 只报"泄露了 traceback"，后面 3 个不检查 → 漏报 | 先 `filter` 收集，最后一次断言列出全部 |
| 自测的 fake 字符串不全 | `SELECT * FROM users` 里没有 `sql`、也没有 `password` → 只命中 2 个 | fake 要故意包含全部关键词 |

## 三条记住的

1. `.include()` 多传参数**被静默忽略** —— 和 Python 里 `def wrapper(row, retry=1)` 吞掉调用方的 `retry=5` 是同一类病
2. **`pm.test` 内部有 try/catch**，所以放进循环里能 4 条独立报告；写在**同一条**里循环，第一个命中就中断
3. **一条永远通过的断言等于没有断言** —— 关键断言要用"必然违规"的输入喂一次，确认它会红

## 为什么自测不进口交付集合

它断言的是**手写的 fake 字符串**，不是接口响应：

- 会让断言数虚高（26 → 27），但接口覆盖率没变
- 它是**永远通过**的用例，交付物里不该有

所以交付集合里 `08-模拟 500` 保持 **3 条**（L1/L2/L3），全集合 **26 条**。
